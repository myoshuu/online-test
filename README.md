### Running inside Docker over HTTP

When the app is built for production (e.g. `docker compose up --build`), cookies default to the `Secure` flag. Browsers ignore secure cookies over plain HTTP, which would make dashboard routes redirect back to `/` repeatedly.  
If you are serving the container over HTTP (typical for local Docker), set `ALLOW_INSECURE_COOKIE=true` (or `COOKIE_SECURE=false`) in your environment so the auth cookie can be stored. Remember to switch the flag off when deploying behind HTTPS.
